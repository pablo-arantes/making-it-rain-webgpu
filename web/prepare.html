2. A ligand, if there is one

A ligand needs parameters, and deriving them in a browser needs a cheminformatics toolkit this page does not carry. So they are uploaded: an OpenMM ffxml holding the ligand's residue template, atom types and parameters, which the notebook and anything with AmberTools can write. The ligand is then matched by the shape of its bonds, so the names inside the file need not match your structure.

No ligand parameters. Heterogens will be dropped.
How to produce one 
from openff.toolkit.topology import Molecule
from openff.toolkit.utils.nagl_wrapper import NAGLToolkitWrapper
from openmmforcefields.generators import SMIRNOFFTemplateGenerator

mol = Molecule.from_file("ligand.sdf", allow_undefined_stereo=True)
NAGLToolkitWrapper().assign_partial_charges(
    mol, "openff-gnn-am1bcc-1.0.0.pt")
open("ligand.xml", "w").write(
    SMIRNOFFTemplateGenerator(
        molecules=[mol], forcefield="openff-2.0.0"
    ).generate_residue_template(mol))

tools/dump_ligand_ffxml.py in the repository does exactly this. Charges come from NAGL rather than AM1-BCC because sqm cannot run in a tab either — deviation 6.
