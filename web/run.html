1. Upload

The engine's contract is OpenMM's own serialisation, so anything XmlSerializer writes is readable here. The restrained system is the one with the equilibration CustomExternalForce added; without it, equilibration runs unrestrained. The PDB is used only as a topology for the final-frame files — coordinates come from the State.

2. Verify this system

Evaluates the whole force field twice: once with the WGSL kernels and once in double precision on the CPU. It also says whether the box can take a barostat, and whether any molecule is split across the periodic boundary — which bonded forces would read as a bond a box long. Slow, and run once rather than per step.

3. Settings

The notebook's fields, with its defaults. The force constant is in kJ/mol/nm² — the notebook's own label says kJ/mol, which is the wrong unit for a term multiplying a squared distance.

A run keeps the screen awake and re-takes the wake lock when the tab comes back, since the browser drops it while hidden. If the GPU is lost it is re-acquired and the run continues from the last completed stage — the same granularity the notebook resumes a Colab session at.

5. Artefacts

Written to the Origin Private File System as the run goes, so they survive the tab closing. One trajectory, log, checkpoint and final frame per stage, plus run.json. The .rst is the restart point; the .pdb is a topology, and holds only 0.001 Å.
